Design — Phase 1: Structural Foundation

Before redrawing poses, fix the underlying coordinate layout and proportions. Every pose uses the same skeleton — getting this right first means Phase 2 is just pose details.

Current Layout — Problems

Proposed Layout — Fixed

Fix

Frame height: 124 → 160 px

The current square frame squashes the character. A 124×160 frame gives room for the longer torso and legs seen in the reference without clipping the feet or the braid.

Fix

Head-to-body ratio

Reference shows roughly 1:3 head-to-body. Current drawing has the head at ~35% of total height. Proposed: head is ~28%, giving a taller, more confident silhouette.

Fix

Back braid clipping

In idle poses the back braid extends to x−56 in drawing units, which clips off the left edge of the canvas. New layout keeps the braid within bounds or trails behind naturally.

Add

Neck segment

Reference shows a visible neck connecting head to torso. Currently head sits directly on the torso. Adding a short neck dramatically improves the read of the character.

Fix

Longer legs / lower feet

Feet are currently fixed at y≈86 in drawing units. Proposed: y≈105, giving legs that are proportionally closer to the reference (roughly half the total body height).

Add

PlayerController hitbox update

Changing the frame height requires updating setSize and setOffset in PlayerController.ts so Pao's physics hitbox still aligns correctly with the new taller sprite.

Only two files change in Phase 1: PaoSpriteFactory.ts (constants + coordinate overhaul) and PlayerController.ts (4 lines to update the hitbox offset for the new frame height). Nothing else in the codebase is touched.
