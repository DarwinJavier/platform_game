# Puchi & Pao's Sparkling Adventure

Local Phaser.js MVP for a 16-bit-inspired 2D platform game.

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Current MVP

The prototype currently includes:

- Title, story, character select, gameplay, game over, and level complete screens
- Puchi and Pao movement differences
- Stars, optional shells, crabs, beach dogs, checkpoint, water zones, powers, and Giant Clam Shrine goal
- Generated placeholder art and Web Audio music/FX
- A reference-guided generated Sunlit Shores backdrop at `public/assets/sunlit-shores-backdrop.png`
- A reference-guided generated terrain tile at `public/assets/sunlit-shores-platform-tile.png`

See [MVP_STATUS.md](./MVP_STATUS.md) for the current implementation snapshot, verification notes, and next playtest priorities.

## Controls

```text
Arrow keys / A-D: Move
Space: Jump / swim
Shift: Run
E: Character power
Esc: Pause in Level 1
Enter: Confirm / retry
M: Mute audio
```
